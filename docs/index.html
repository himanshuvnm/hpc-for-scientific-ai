START WITH THE DEFINITIONS

Precise language.
Clear computational scope.

AI, machine learning, scientific computing, and HPC overlap—but they are not synonyms. These are working definitions for the course.

Scientific AI

AI methods used to advance scientific modeling, prediction, inference, experimentation, analysis, or discovery. AI for Science is a widely used related term.

Scientific ML (SciML)

Machine learning developed or applied for scientific and engineering problems, often connected with mathematical models, scientific data, or numerical methods.

HPC for Scientific AI

Scalable computation supporting AI-enabled scientific workflows, including model execution, training, scientific data processing, and large-scale evaluation.

HPC for Scientific ML

Scalable computing for scientific ML specifically: parallel training, accelerators, scientific data pipelines, inference, and performance optimization.

Our first two labs teach HPC and numerical science, not AI. AI-driven scientific labs will be introduced in later modules. Read the complete, sourced terminology guide →
