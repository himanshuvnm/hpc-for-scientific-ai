# Instructor guide — HPC for Scientific AI

**Suggested format:** 12 weeks, one lecture + one lab per week; suitable for advanced undergraduates or beginning graduate students with introductory Python experience.

**Prerequisites:** shell basics helpful; Python functions, loops, lists; basic differential equations for the optional mathematical error discussion.

## Course outcomes

Students completing the full curriculum should be able to: (1) map a numerical problem to hardware; (2) safely prepare and submit jobs; (3) verify numerical results independently of performance; (4) assess parallel efficiency; and (5) produce reproducibility artifacts with correct resource accounting.

## Current release (v0.1)

Only Lab 01 and Lab 02 are runnable. Do not advertise the remaining modules as finished; see [ROADMAP](../ROADMAP.md).

## Accessibility and access

Every lab has a laptop-only completion path. Real-HPC execution is optional unless the course can guarantee equitable cluster access and an approved educational allocation. Never require students to publish private computing-account information in their reports.

## Grading

Use the [assignment](assignments/assignment-01.md) and [rubric](rubrics/scientific-hpc-lab.md). Prioritize correctness and explanation, not faster hardware or greater resource usage.
